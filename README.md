
# Week 1 - Python Assessment

## Project Overview
This project contains my Week 1 Python assessment.
It covers Python fundamentals, OOP, file handling, APIs, NumPy, Pandas, Matplotlib, Git and GitHub.

## Project Structure
- data/ - CSV and JSON files
- notebooks/ - Jupyter notebooks
- reports/ - Analysis reports and charts
- src/ - Python source code
- requirements.txt - Required Python packages

## Setup Instructions

### 1. Clone the repository
```bash
git clone https://github.com/Jegathesh-1712/week1-assessment.git
cd week1-assessment
```

### 2. Create virtual environment
```bash
python -m venv venv
```

### 3. Activate environment (Windows)
```bash
venv\Scripts\activate
```

### 4. Install dependencies
```bash
pip install -r requirements.txt
```

### 5. Run the project
Open the Jupyter notebook inside the notebooks folder and run the cells.
